lost phone • spoiler-free overview
a found laptop. two people stuck at a flooded jeep terminal. an owner who is nowhere around.

manila, philippines • august 18, 2026

lost phone is a single-file browser mystery game. you explore somebody else's laptop, figure out who it belongs to, and decide what information is actually useful before the night moves on.

the game is mostly text, fake desktop apps, cached messages, files, photos, logs, conversations, and choices. there is no combat and no fast reaction mechanic. most of the game is reading, comparing, remembering, and deciding what deserves your attention.

starting a game

press start on the main menu, choose Alon or Haraya, then follow the opening conversation until the laptop desktop becomes available.

the two POVs share the same night and the same laptop, but their dialogue, choices, and some personal reactions are different. choosing one does not permanently lock the other.

if you already have local progress, the main menu shows continue. that resumes the saved game instead of beginning a new opening.

what you actually do

use the laptop like a messy real computer. click desktop shortcuts, open folders, read chats, inspect photos, check logs, and move between apps. new information and new parts of the story become available as you discover enough relevant context.

you are not expected to read every single item. a lot of the laptop is ordinary clutter. if something seems useful, remember it, bookmark it when case tools become available, or return to it later.

there is no single perfect app order. if one area feels empty, close it and try something else.

controls

mouse / touch: click or tap buttons, files, chats, tabs, and choices.

scroll: individual apps and document viewers can scroll independently. on mobile, drag inside the panel you want to move.

_ / ×: either window control closes the current laptop window. reopening the shortcut brings it back.

? on the desktop opens the full How to Play guide at any time.

progress + saving

progress happens through discoveries, conversations, and story choices. the game tracks what you have already opened, so repeatedly clicking the same file will not normally count as new progression.

the game autosaves during play and also has a Save app for manual saving. saves are stored locally in your browser. clearing site data or changing browsers can remove them.

the Save app can also export a save file if you want a separate backup.

internet inside the story

the HTML game itself does not need internet content to run. inside the fiction, however, the laptop can be offline or online. cached information and newly synced information are treated differently by the story.

ending the game

the night eventually reaches a decision point. available choices depend on what you have actually established and which parts of the final situation you discovered.

there are multiple endings. they are not labeled as a simple good / bad / true hierarchy, and you do not need to see every one to finish a playthrough.

codes

the main menu and laptop include a code entry field for development/testing shortcuts. the game does not display the codes or suggest one. normal players can ignore the field completely.

best first run: play normally, read what interests you, use the timeline when it appears, and don't worry about completing every folder.

everything needed to play is inside this HTML file. no installation is required beyond opening it in a modern browser.

how to play

simple control guide • no clue locations • no easter-egg spoilers
the game moves slowly on purpose. explore, then use a few simple case controls to show how you are organizing what you found.

the easy version

start → choose Alon or Haraya → explore → reach the current clue target → use the case control shown in Our Notes → the next part opens → repeat until the final decision.

You still do not need to read every file. The game asks for a small number of strong discoveries in each section, then one simple case action when needed.

☷ our notes

Click ☷ on the taskbar. Our Notes is an automatic list of important things Alon and Haraya have already noticed.

You do not type in it. Scroll through it when you forget what happened.

If you are stuck, click need a lead? inside Our Notes. It gives one optional next-step hint based on your current progress.

messynger: inbox / archived / requests

At the beginning, you only have the locally available inbox cache.

  • inbox — available from the start.
  • archived — unlocks later when the investigation reaches the account's deeper cached history.
  • requests — not locally cached at first; it only becomes available after the laptop legitimately reconnects.

If a tab has a lock, keep playing. You are not missing a control.

🧷 case board → our timeline

The Case Board appears early, after the basic owner/contact setup. At first it is just your discovered evidence and case controls.

Later, when the final-night investigation becomes important, the same app expands into Our Timeline. Known events show a time and description; unknown sections stay ???.

Each evidence/timeline row can be organized with the controls below. The game only asks you to use a few of them, not label everything.

case tools — required, but simple

none of the case tools grade you or secretly pick your ending — they're just for keeping your own head straight.

When Our Notes tells you a case action is required, open 🧷 Case Board / Our Timeline. There is a confidence dropdown beside each clue, a ☆ flag button for anything you want to keep nearby, and a review comparison button when the board puts two discovered pieces together.

You only have to use the small number shown in the current-step box. The story still waits for those actions before moving on.

wifi / hotspot

Wi-Fi stays locked until the story unlocks it — you'll know when it does. After that, the taskbar button connects the laptop to Alon's hotspot so uncached information can arrive.

saving

💾 quick-saves immediately. ☷💾 opens the full Save / Load window.

The game also autosaves. Continue on the main menu loads your local save.

if you get stuck

  1. open ☷ Our Notes.
  2. press need a lead?.
  3. try another normal app instead of repeatedly clicking the same file.
  4. when Timeline exists, review the known timestamps and flagged items.

Check the current progress line in Our Notes or the Case Board. You still need the full clue target for each act, but you should always be able to see what kind of progress is missing.

cheat codes

The main menu and laptop both have a code field. Type a code you already know and press Enter. The game never shows or suggests the codes.
